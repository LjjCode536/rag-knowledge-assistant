# ADR-0008: 生成指标与 CI 门禁:规则法忠实度 / 引用准确率 / 双向拒答正确率

**Status**: accepted

## Context

T06 只产出检索指标(Recall@K / MRR / NDCG / HitRate)与「检索口径」的拒答正确率,生成质量(有没有编造、引用是否给了依据、该回答的有没有被误拒)无处安放。T07 打开高级检索开关后,门禁需要覆盖的维度更多(消融报告已在 `docs/iterations/0002`)。M5 已把生成链路落到 `/api/v1/chat`:统一拒答文案、`generator` / Token 用量留痕(ADR-0007)。

约束:

1. **CI 无密钥也能跑**:评估默认走进程内 + 确定性向量替身(ADR-0003 收口),真实 embedder / 重排 / LLM-as-Judge 都需要密钥与计费;
2. **指标必须可复现**:同一数据集、同一分词口径,逐字节可 diff;
3. **口径不能散落**:评估服务、报告与 CI 门禁共用同一把尺子;
4. 教材第 44 章给了规则法 Faithfulness(条文支撑 + 过度承诺扣分)与 Citation Accuracy 的最小实现。

## Decision

- **生成指标同一轮评估产出**:评估器在逐用例检索评估后追加一次 `/api/v1/chat` 调用(同一问题、同一 top_k、同一过滤与拒答阈值),回答、拒答原因、引用全部写进 `case_results`;忠实度 / 引用准确率 / 拒答正确率(生成口径)进入报告的 `generation` 块,并按品类产出 `generation_categories`。
- **忠实度(规则法)**:回答剥掉套话短语后按标点切开分句;每个分句在**所引资料**里的词面(二字滑窗 + 拉丁词,与确定性替身 / BM25 同一分词)支撑率 ≥ 0.5 记为被支撑;命中任一内容分句无支撑即降低整体比例,资料之外的「保证 / 百分百 / 立即到账 / 无需审核」类过度承诺每条额外扣 0.2 并在报告中留痕。未引用任何内容就作答(或整句为空)= 0。
- **引用准确率(规则法)**:一条引用支撑回答 = 该引用的词面与回答有 ≥ 2 个交集;比例 = 支撑引用数 / 全部引用数。拒答没有回答内容,不进入忠实度与引用准确率均值。
- **拒答正确率扩展为双向(生成口径)**:`refused == should_refuse` 在全部用例上的比例——应拒答的用例被误答、可回答的用例被误拒,两边都记为失败;报告保留 T06 的「检索口径」(应拒答用例未出现高分命中)不变,两条口径在报告中并存、各自注明。
- **生成器选择**:评估 CLI `--qa-generator rule`(默认,零成本、逐字复现)/ `llm`(显式选择,需密钥);无密钥环境强制规则版,LLM 作答不得静默出现在无密钥报告中。
- **门禁**:CLI `--check` 在报告产出后对阈值断言,跌破任一下限 exit 1;阈值经 `--min-*` 可调,默认值记录的是无密钥(CI)子集的下限。CI 工作流(`.github/workflows/ci.yml`)显式传全部阈值,红灯可用「把阈值拉到不可能的水平」复现一次。
- **替身分数口径**:确定性替身的余弦分数分布与生产 bge-m3 不同——同一个 `qa_min_score=0.35` 在替身口径下会把 20+ 条可回答用例全部压成拒答。CI 评估显式传 `--min-score 0.07`(替身操作点),报告中的 `min_score` 与检索口径、生成口径共用同一值;换 embedder 需重新校准阈值并在报告中注明。

## Consequences

- **收益**:「编造率上升」「误拒率上升」「引用不给依据」「回归悄悄进主干」四类风险各有一个可断言的数字;AGENTS.md 的「每次迭代有前后指标对比」从检索扩展到了生成;CI 红灯显式可复现。
- **代价**:每轮评估多 26 次 `/chat` 调用(进程内规则版毫秒级);忠实度和引用准确率都是词面规则,判断不了语义 paraphrase,教材明确该层的完整方案是 LLM-as-Judge / Ragas(可选后续)。CI 阈值绑定替身分数口径,更换 embedder 必须重校 `--min-score` 与阈值。
- **后续**:上游评估(`--base-url` + `--qa-generator llm --embedder upstream`)产出真实 LLM 的同一批指标字段;若引入 LLM-as-Judge,忠实度判分替换为语义级,规则法继续作为 CI 的无密钥底线。
